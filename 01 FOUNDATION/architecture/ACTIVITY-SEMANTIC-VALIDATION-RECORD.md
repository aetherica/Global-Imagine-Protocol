## 4. Semantic Stress Tests

### Activity / Process / Procedure / Result

Activity is the occurrence layer. Process is a broader transformation/development/progression or organized temporal course. Procedure is specification-level. Result is generated output. These responsibilities remain distinct.

### Execution

Execution is a procedure-driven Activity pattern, not a universal parent of every Activity.

### Observation / Measurement

Observation obtains information about a phenomenon/feature/property/state. Measurement specifically obtains quantity value(s). No universal subclass assertion is introduced.

### Acquisition / Camera / Lens / Sensor

Camera is system-level, Lens is optical component/assembly, Sensor is sensing subsystem, and Acquisition is the actual capture occurrence. The hardware subsystem is not rewritten as an Activity hierarchy.

### Processing / Algorithm / Software / Process

Algorithm is method, Software is implementation, Processing is actual operation, and Process remains a broader temporal/organizational semantic concept. Lexical similarity does not collapse the layers.

### Calibration

Calibration is the metrological relationship-establishing operation and remains distinct from Adjustment, Verification, Maintenance, Measurement, and calibration output information.

## 5. Visitor Universe Validation

Visitor Universe is treated as an entry/traversal model rather than an alternate semantic authority. Novice, professional, and expert visitors may receive different orientation and depth into the same canonical Activity knowledge. No audience-specific duplicate semantics were introduced.
