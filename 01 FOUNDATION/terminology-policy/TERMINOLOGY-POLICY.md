# GIOP V3.1 — Terminology Policy

Status: CANONICAL

## Purpose

Keep GIOP language controlled without collapsing different meanings into one label.

## Rules

Preferred terms, aliases, synonyms, abbreviations, vendor terms, historical terms, and deprecated expressions must remain distinguishable.

A term is not a semantic definition merely because it appears in a glossary.

Foundation defines usage policy. Canonical definitions belong to `02 SEMANTICS`; controlled term collections belong to the Appendix language layer.

Where multiple disciplines use one word differently, GIOP must preserve the distinction explicitly rather than forcing a false equivalence.

Terminology changes should be traceable so retrieval and historical interpretation remain possible.
