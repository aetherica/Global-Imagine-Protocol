## Responsibility

The Perception layer owns reusable semantic concepts whose primary responsibility is an observer-relative perceptual phenomenon, experience, organization, appearance, or perceptual attribute.

The generic canonical anchor is `SEM-PERCEPTION-GENERIC-001`.

## Scope

Perception covers perceptual phenomena without requiring a particular biological mechanism, implementation, numerical measurement, or conscious verbal report.

The current semantic scope includes:

- perceptual experience;
- perceptual organization;
- perceptual appearance;
- perceptual attributes;
- spatial and temporal perceptual phenomena;
- perceptual constancy and transformation;
- perceptual illusion and related non-veridical phenomena;
- specialized perceptual domains such as visual, colour, material, image-quality, and multisensory perception.

These are content families and controlled specialization areas, not an automatic universal class hierarchy.

## Boundary

`Perception ≠ Observer ≠ Observer Model ≠ Observation ≠ Property ≠ Quantity ≠ Quantity Value ≠ Condition ≠ Context ≠ State ≠ Representation ≠ Process ≠ Activity ≠ Model ≠ Metric`

Perceptual report, rating, response, and measurement result are evidence or representation of perceptual phenomena unless an independent semantic responsibility is established.

## Authoring Rule

Use the Foundation sequence:

`IDENTITY / METADATA → 5W1H → SEMANTIC DEFINITION / CORE DISTINCTIONS → DOMAIN-SPECIFIC TECHNICAL DEPTH → TRUST / EVIDENCE / VALIDATION → LIFECYCLE → RELATIONS / RETRIEVAL`

Do not create a new canonical Perception concept merely because a term is common in psychology, imaging, display, colour, or AI literature. First resolve its primary responsibility and cross-layer boundary.

Recognition, scene understanding, categorization, decision, report, metric, capability, and implementation-oriented machine perception remain cross-layer/deferred until independent responsibility is established.

## Evidence Basis

The implementation is based on verified terminology and research spanning CIE visual and colour terminology, vision science, psychophysics, observer-model literature, subjective image-quality methodology, material perception, and multisensory perception, together with GIOP Foundation controls.

Research evidence is not automatically equivalent to GIOP canonical status. The registry records candidate disposition and promotion decisions.

## Visitor Universe

Visitor Universe is an access, orientation, retrieval, and entry-depth system. It does not define semantic identity.

The same canonical Perception knowledge supports different entry depths:

- beginner: identity, plain-language meaning, and essential distinctions;
- practitioner: major phenomena, attributes, qualifiers, and application relevance;
- expert: psychophysics, evidence, observer/task dependence, and cross-layer boundaries;
- machine/AI: stable identity, definition, relations, provenance, validation, and deterministic retrieval anchors.

The ordinary semantic entry must not contain a `Visitor Universe` section.
