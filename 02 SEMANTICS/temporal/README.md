# Temporal Semantic Layer

**Status:** CLOSED — CURRENT V3.1 TEMPORAL NUCLEUS
**Version:** 1.0.0

The Temporal layer owns reusable temporal semantics. `Time` is the current canonical nucleus. It provides the reference needed to distinguish instants, intervals, durations, temporal positions and temporal context across phenomenon, acquisition, execution, processing, result and presentation.

Temporal semantics are not collapsed into ordinary Quantity semantics. A duration may be quantified, but temporal identity and ordering remain distinct responsibilities.

Visitor Universe routing changes entry depth only; it never creates audience-specific temporal definitions.

Future temporal relations or specialized temporal concepts require independent semantic validation and promotion. Existing canonical Relation authority must not be silently expanded by mentioning a temporal relation here.

- `SEM-TEMPORAL-TIME-001` — Time — Active

## Boundary

Temporal semantics ≠ timestamp value ≠ duration quantity ≠ state ≠ event/activity ≠ relation assertion.
