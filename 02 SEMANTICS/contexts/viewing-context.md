# Viewing Context

**GIOP ID:** `SEM-CONTEXT-VIEWING-001`  
**Artifact Type:** Canonical Semantic Concept  
**Status:** CANONICAL  
**Primary Responsibility:** Visual viewing frame

## 5W1H Orientation

**What:** The contextual frame in which a visual stimulus or representation is viewed and interpreted.

**Why:** Appearance, judgment, assessment, and interpretation can depend on stimulus, background, surround, adaptation, display, observer, geometry, distance, illumination, and environment.

**How:** By identifying the relevant viewing and perceptual circumstances around the stimulus or representation.

**Where:** Displays, color appearance, image evaluation, subjective assessment, visual quality testing, imaging production, and human-computer viewing.

**Who:** Human observers, assessors, viewers, display systems, and machine models that explicitly model viewing conditions.

**When:** During viewing or when a visual interpretation is intended to be reproduced or compared.

## Canonical Definition

**Viewing Context is a contextual frame specifying the relevant circumstances under which a visual stimulus or representation is viewed and interpreted, including applicable stimulus, background, surround, adaptation, display, geometry, observer, illumination, environment, and purpose.**

## Scope

Relevant components may include stimulus, proximal field, background, surround, adapting field, display characteristics, viewing distance, observation angle, observer, room environment, illumination, reflection conditions, and assessment purpose.

## Distinctions

Viewing Context is broader than a Viewing Condition. It is not Perception, Observer, Display, Illumination Condition, or a color-appearance attribute. A perceptual result can be influenced by context without context being the perception itself.

## Evidence / Provenance

Strongly supported by CIE viewing/color-appearance concepts involving stimulus, background, surround and adaptation; ITU-R BT.500 viewing and assessment conditions; and high-fidelity colorimetry requirements that explicitly include viewing circumstances.

## Cross-Layer Relations

Connects to Observer, Perception, Display-related Classes, Conditions, Color semantics, Representations, Assessment Context, and spatial/temporal semantics.

## Trust / Validation

Viewing claims should retain relevant contextual variables where they materially affect interpretation or comparison. A stated viewing context does not guarantee perceptual equivalence.

## Lifecycle

**CANONICAL — V3.1.**

## Machine / AI Interpretation

Use Viewing Context as a qualification for visual interpretation and appearance-model inputs. Do not infer human perception solely from display or physical stimulus data. If relevant viewing variables are missing, preserve uncertainty.
