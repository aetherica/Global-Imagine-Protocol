# Linearity

**ID:** SEM-PROPERTY-LINEARITY-001
**Status:** CANONICAL
**Semantic Type:** PROPERTY

## Semantic Definition

Linearity is a property describing how closely a defined system's output-response relationship follows a specified linear reference relationship over a defined input or operating range.

## Bearer / Applicability

Applicable to sensors, imaging systems, measuring systems, and other systems for which an input-output relationship and reference linearity model are defined.

## Quantification Boundary

Linearity error, deviation from a fitted line, residuals, or other numerical indicators are quantitative realizations or measurement results, not the Property itself.

## Distinctions

Linearity is distinct from sensitivity, which concerns response dependence, and from accuracy, which concerns agreement with a reference or true value under a measurement definition.

## Evidence and Provenance

Supported by measurement and imaging characterization practice, including EMVA 1288 treatment of linearity and linearity error.

## Machine Interpretation

Presence of this Property does not establish a numerical linearity range or error without explicit quantitative evidence.

## Semantic Boundary

The canonical concept is the characteristic of linear response behaviour. Specific test procedures, fitted models, coefficients, and error values remain outside this Property definition.
