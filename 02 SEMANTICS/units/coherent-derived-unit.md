# Coherent Derived Unit — `SEM-UNIT-COHERENT-DERIVED-001`

**Preferred semantic name:** Coherent Derived Unit  
**Semantic ID:** `SEM-UNIT-COHERENT-DERIVED-001`  
**Layer:** Unit  
**Status:** Candidate / implementation target  
**Parent semantic:** `SEM-UNIT-DERIVED-001`

## 5W1H

**What:** A Coherent Derived Unit is a Derived Unit constructed from the selected base units of a specified coherent system without an additional numerical proportionality factor.

**Why:** It provides a normalized derived-unit structure that follows the algebra of the governing quantity system directly.

**Who:** Coherence is determined relative to the relevant system of quantities and its selected base units.

**Where:** It applies within coherent systems of units and their derived-unit structures.

**When:** A derived unit has coherent status when its expression satisfies the coherence condition of the specified system.

**How:** Its unit expression is formed as the product of powers of the system's base units, with proportionality factor one.

## Semantic definition

A Coherent Derived Unit is a Derived Unit whose expression in a specified coherent system of units is formed from powers of the system's base units without an additional proportionality factor.

## Scope and boundary

Coherence is system-relative and must not be treated as an absolute property independent of system context.

`Coherent Derived Unit ⊂ Derived Unit`  
`Coherent Derived Unit ≠ Coherent System`  
`Coherent Derived Unit ≠ Quantity Dimension`  
`Coherent Derived Unit ≠ Unit Expression`

## Distinctions

Every coherent derived unit is derived, but not every derived unit is coherent. A Unit Expression describes construction syntax/structure; Coherent Derived Unit describes a semantic status of a derived unit within a specified system.

## Cross-domain significance

The concept supports dimensional reasoning, unit-system comparison, engineering calculation, interoperability, and normalization of derived measurements.
