# Base Unit — `SEM-UNIT-BASE-001`

**Preferred semantic name:** Base Unit  
**Semantic ID:** `SEM-UNIT-BASE-001`  
**Layer:** Unit  
**Status:** Candidate / implementation target  
**Parent semantic:** `SEM-UNIT-GENERIC-001`

## 5W1H

**What:** A Base Unit is a conventionally adopted unit for a base quantity within a specified system of quantities.

**Why:** It provides the reference foundation from which coherent derived units can be constructed.

**Who:** Its adoption is governed by the relevant metrological or standards authority and system convention.

**Where:** Base units operate within a defined system of quantities/units; they are not universally base units independent of system context.

**When:** A unit has base status when the governing system designates it for a base quantity.

**How:** Derived-unit structures can be formed from powers/products of the system's base units.

## Semantic definition

A Base Unit is a Unit designated by a specified system of quantities and units as the adopted measurement unit for one of that system's base quantities.

## Scope and boundary

Base status is system-relative. A Base Unit is not identical to the base quantity, the quantity dimension, or every unit that happens to be elementary in a domain.

`Base Unit ≠ Base Quantity`  
`Base Unit ≠ Quantity Dimension`  
`Base Unit ≠ Numerical Value`  
`Base Unit ≠ Measuring Instrument`

## Distinctions

The generic Unit concept owns measurement-unit identity. Base Unit adds system-governed foundational status. Derived Unit is constructed from quantity/unit relations and is not automatically base merely because it is commonly used.

## Cross-domain significance

Base-unit semantics support metrological interoperability, dimensional reasoning, coherent-unit construction, standards comparison, and machine-readable quantity-value exchange.

## Trust and evidence

JCGM VIM and BIPM SI materials provide primary metrological evidence. ISO 80000 provides complementary normative terminology. External ontologies are implementation evidence only.

## Visitor Universe

Visitor presentations may explain base units through domain examples without changing the system-relative definition.
