# Models

**Semantic Area:** Model and Purpose-Specific Abstraction  
**Status:** PROVISIONAL — V3.1 CANDIDATE SEMANTIC LAYER  
**Version:** 0.1.0  
**Primary Responsibility:** Purpose-specific constructs that abstract, characterize, simulate, predict, explain, design, or otherwise stand for a selected target system, phenomenon, structure, behavior, or domain of interest.

## Scope

The `models` area establishes a generic semantic responsibility for Model without making Model an AI-only, computational-only, scientific-only, or representation-only concept. A model may be conceptual, mathematical, physical, computational, statistical, simulation-based, learned, or hybrid when the primary semantic claim concerns the purpose-specific abstraction itself.

The current phase establishes one generic candidate entry: `SEM-MODEL-GENERIC-001 — Model`. Specialized model vocabularies remain controlled candidates and are not independently canonicalized by lexical association.

## Current State

The folder was previously repository-placeholder-only. This phase materializes the generic Model responsibility and its governance artifacts while deliberately retaining `Provisional` status pending independent promotion review.

The presence of a Model entry therefore does not add a new Active canonical layer to GIOP. It establishes a bounded candidate semantic responsibility for subsequent validation.

## Core Boundary

Model is distinct from Representation, because a model is identified primarily by its modeling purpose, target relationship, abstraction, assumptions, or interpretive role rather than by an information-bearing format or encoding.

Model is distinct from Algorithm because an algorithm is a computational method, whereas a model is the object or construct that is formulated, parameterized, analyzed, simulated, trained, compared, or used for reasoning.

Model is distinct from Software because software is an implementation artifact. A software implementation may realize, execute, manipulate, or expose a model without becoming the model itself.

Model is distinct from Activity, Process, Procedure, Result, Property, State, Condition, Context, Quantity, and Relation. Those layers retain their established primary responsibilities.

## Controlled Candidates

The following terms are retained as candidate vocabulary and require independent semantic review before promotion beyond the generic Model responsibility:

- scientific model
- mathematical model
- physical or scale model
- computational model
- simulation model
- statistical model
- machine-learning model
- AI model
- causal model
- predictive model
- world model
- system model
- architecture model
- digital-twin model

These terms may denote useful model types or dimensions, but lexical familiarity is not sufficient evidence for separate GIOP semantic identity.

## Governance Position

External standards, formal modelling traditions, scientific literature, and implementation practice are evidence for semantic synthesis. They do not by themselves determine GIOP authority.

Visitor Universe remains an entry-depth and retrieval mechanism. It does not create visitor-specific model identities.

The immutable proof ledger is not modified by this phase.
