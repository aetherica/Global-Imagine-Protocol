# Model Semantic Folder

**Status:** PROVISIONAL — V3.1 CANDIDATE SEMANTIC LAYER

This folder establishes the generic GIOP Model responsibility as a bounded candidate layer. Model denotes a purpose-specific abstraction or construct relative to a selected target and purpose.

The folder does not treat Model as a synonym for Representation, Algorithm, Software, Activity, Process, Result, State, Condition, Context, Quantity, Property, Relation, or BIL integrity. It also does not create visitor-specific model identities.

## Canonical Candidate

`SEM-MODEL-GENERIC-001 — Model`

## Current Boundary

Model identity is target- and purpose-oriented. A representation can carry a model; an algorithm can construct or use one; software can implement it; activities can train, fit, simulate, evaluate, or apply it; results can be produced from it. None of those surrounding artifacts or occurrences becomes the model solely by association.

## Current Specialized Vocabulary

Scientific model, mathematical model, physical/scale model, computational model, simulation model, statistical model, machine-learning model, AI model, causal model, predictive model, world model, system model, architecture model, and digital-twin model remain controlled candidates.

See `MODEL-FOLDER-CLOSURE-AUDIT.md` for the current closure decision and validation status.
