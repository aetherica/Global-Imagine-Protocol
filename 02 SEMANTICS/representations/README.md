# Representations

**Semantic Area:** Representation and Information-Bearing Forms  
**Status:** Active Canonical Scope — First Advanced Extension Batch Closed  
**Version:** 2.0.0  
**Primary Responsibility:** Information-bearing forms through which canonical information, results, resources, or other semantic content are expressed, exchanged, stored, presented, or made available for interpretation.

## Scope

The `representations` semantic area defines the canonical meaning of Representation and the principal semantic concepts required to describe information-bearing forms without collapsing representation, format, encoding, storage, presentation, perception, or conformance into one layer.

## Core Boundary

Representation is not synonymous with Information/Knowledge, Result, Dataset, File/Bitstream, Format, Encoding, Serialization activity, Media Type, Compression, Packaging, Display, Observation, Perception, Measurement Result, Conformance, Model, Algorithm, Software, State, Action, Relation, Property, Context, Condition, or Process.

A related concept must be routed through its own semantic responsibility or an appropriate relation/cross-layer reference rather than absorbed into Representation.

## Multidimensional Organization Rule

Representation families must not be modeled as a single flat taxonomy when classification dimensions are orthogonal. Referent, modality, structure, abstraction, temporal scope, agent coupling, uncertainty, spatial organization, and computational realization may intersect.

Therefore:

`Representation → multidimensional classification / specialized responsibility`

is preferred over universal single inheritance.

## Advanced Batch Closure

The first advanced extension dataset has been fully promoted after independent semantic review. Each concept passed identity, primary responsibility, existing-entry check, boundary, evidence, relation authority, cross-layer validation, lifecycle, and retrieval gates.

The completed batch covers relation-centric, affordance, action, event, spatiotemporal, causal, predictive, neural-field, program, intermediate, digital-twin, skill, trajectory, scene, world, and map representations, in addition to the previously promoted belief and object-centric representations.

No new relation authority was introduced. Existing semantic layer ownership remains intact.

## Visitor Universe and Entry Depth

Visitor Universe does not create separate representation ontologies or audience-specific semantic copies. The same canonical entries support different entry depths and retrieval patterns. No ordinary semantic entry contains a separate Visitor Universe section.

## Authoring Standard

Representation entries follow the Foundation authoring pattern while remaining artifact-specific: identity/metadata, 5W1H orientation where useful, semantic definition, scope/structure, distinctions, boundary cases, technical significance, relations, provenance/evidence, trust/validation, lifecycle, and retrieval anchors.

## Provenance and Evidence

Evidence was reviewed across multiple source traditions: Web and information standards; RDF/DCAT/PROV; preservation; graph and relational representation; embodied robotics and affordances; action and skill representations; event-based sensing; spatial-temporal systems; causal representation learning; predictive representation and world models; neural fields; compiler/program IR; digital twins; trajectory learning; scene representation; and robot mapping.

External specifications and literature remain evidence sources rather than GIOP authority.
