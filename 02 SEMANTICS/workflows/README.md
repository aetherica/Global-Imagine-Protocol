# Workflow / Procedure Semantic Layer

**Status:** CLOSED — CURRENT V3.1 PROCEDURE NUCLEUS
**Version:** 1.0.0

The layer owns reusable procedure/workflow specifications: descriptions of how an activity or execution is to be carried out. The current canonical nucleus is Measurement Procedure.

## Canonical entry

- `SEM-WORKFLOW-MEASUREMENT-PROCEDURE-001` — Measurement Procedure — Active

## Boundary

Procedure ≠ Activity ≠ Execution ≠ Algorithm ≠ Result. A procedure may specify an activity/execution without becoming the occurrence itself.

Visitor Universe controls entry depth only. Future procedure/workflow concepts require independent validation.
