## Routing Notes

- `Processing` is already an Active Activity concept and is not duplicated here.
- `Execution` is already an Active Activity concept and is not duplicated here.
- `Procedure` is not silently authored as Process.
- `Result` remains a separate semantic responsibility.
- Workflow documents and process diagrams are Representations/artifacts, not automatically Process instances.
