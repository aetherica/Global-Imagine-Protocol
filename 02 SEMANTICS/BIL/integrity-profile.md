# BIL Integrity Profile

Status: CANDIDATE — BIL V3.1
Semantic ID: SEM-BIL-INTEGRITY-PROFILE-001

## Definition
An Integrity Profile is a declared application context that selects relevant subjects, integrity dimensions, permitted variations, evidence classes, validation methods and decision policy without changing the underlying BIL semantics.

## Profile families
Human; animal/wildlife; plant/organism; multi-organism; sports; dance; fashion; documentary; scientific; VFX; digital human; synthetic biological form; still; video; 3D/4D.

## Boundary
Profile ≠ ontology; Profile ≠ genre ontology; Profile ≠ separate knowledge base; Profile ≠ replacement semantic layer.

## Visitor Universe
Profiles route the same canonical concepts to task-relevant entry paths. Profile selection never duplicates canonical definitions.
