# BIL Permitted Variation

Status: CANDIDATE — BIL V3.1
Semantic ID: SEM-BIL-PERMITTED-VARIATION-001

## Definition
Permitted Variation specifies a declared class or range of change that remains compatible with an Integrity Claim under a defined context and transformation intent.

## Examples
Pose change, expression change, illumination change, clothing change, viewpoint change, declared VFX transformation, animation and other context-qualified variations.

## Boundary
Permitted Variation ≠ Deviation; Permitted Variation ≠ Drift; Permitted Variation ≠ arbitrary change; Permitted Variation ≠ invariance.

## Rule
Variation is interpreted only relative to reference, scope, context and declared transformation policy.

## Visitor Universe
Profiles may expose different permitted-variation sets while preserving the same underlying concept.
