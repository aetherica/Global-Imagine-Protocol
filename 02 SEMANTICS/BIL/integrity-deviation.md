# BIL Integrity Deviation

Status: CANDIDATE — BIL V3.1
Semantic ID: SEM-BIL-INTEGRITY-DEVIATION-001

## Definition
Integrity Deviation is an observed or inferred difference between a reference-defined expectation and an evaluated target within a declared scope.

## Boundary
Deviation ≠ failure; Deviation ≠ error; Deviation ≠ drift; Deviation ≠ violation until interpreted against applicable constraints and permitted variation.

## Model
Reference → expected condition → observed target → deviation measurement/description → interpretation.

## Existing routing
Magnitude or numerical characterization routes to Quantity/Measurement where applicable. The integrity interpretation remains BIL-owned.
