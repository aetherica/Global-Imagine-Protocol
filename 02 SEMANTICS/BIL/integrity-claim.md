# BIL Integrity Claim

Status: CANDIDATE — BIL V3.1
Semantic ID: SEM-BIL-INTEGRITY-CLAIM-001

## Definition
An Integrity Claim is a scoped assertion that a specified integrity property, correspondence, or preservation condition holds between a declared reference and an evaluated representation, configuration, state, or result.

## Claim model
Reference → Claim Target → Integrity Claim → Evidence → Evaluation → Decision.

## Scope
Claims may concern identity, structure, state, interaction, appearance, spatial correspondence, temporal continuity, or contextual plausibility.

## Boundary
Claim ≠ Property; Claim ≠ Result; Claim ≠ Evidence; Claim ≠ Decision; Claim ≠ generic truth statement.

## Qualification
Every claim requires scope, target, reference, context, applicable variation policy, evidence status, provenance, and evaluation status.

## Visitor Universe
Depth 0 explains the claim idea; deeper levels expose formal scope, evidence, validation and machine representation. Meaning remains invariant.
