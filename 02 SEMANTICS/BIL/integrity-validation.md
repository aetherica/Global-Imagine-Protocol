# BIL Integrity Validation

Status: CANDIDATE — BIL V3.1
Semantic ID: SEM-BIL-INTEGRITY-VALIDATION-001

## Definition
Integrity Validation is the activity or procedure by which an Integrity Claim is tested against applicable evidence and constraints.

## Existing-layer routing
The actual validation activity belongs to Activity/Workflow semantics. Measurements and quantities remain in their existing layers. BIL owns the integrity-specific validation specification and interpretation context.

## Boundary
Validation ≠ metric; Validation ≠ evidence; Validation ≠ decision; Validation ≠ generic measurement.

## Rule
Each validation must identify claim, evidence, method, applicable constraint, uncertainty and result status.
